# 🦊 Sable Fox Studio Website

[![Status](https://img.shields.io/badge/Status-In%20Progress-orange?style=flat-square)](https://github.com/deanfoxcd/sable-fox-studio)

A beautiful, modern website for Sable Fox Studio – a custom art studio in Knoxville, TN. This site is designed to showcase artwork, provide information about the artist, and offer a seamless way for visitors to inquire about commissions or connect via social media.

---

## 🚀 Live Demo

👉 [Visit the Sable Fox Studio Website](https://sable-fox-studio.vercel.app)

---

## ✨ Features

- Browse portfolio of artwork and projects
- Responsive design
- Modern UI powered by React
- Easy-to-use commission inquiry form
- Social media integration
- Journal/blog section for updates (still coming)

## 🛠️ Getting Started (work in progress regarding Supabase)

To run this project locally:

1. **Clone the repo**
   ```bash
   git clone https://github.com/deanfoxcd/sable-fox-studio.git
   cd sable-fox-studio
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Set up environment variables**
   - If needed, copy `.env.example` to `.env.local` and fill in any required credentials.
4. **Start the development server**
   ```bash
   npm run dev
   ```
5. Visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🧰 Tech Stack

- **Frontend:** Next.js (React with TypeScript, SSR and API routes), Flowbite/Flowbite-React
- **Backend:** Supabase
- **Deployment:** Vercel (coming 7/3)
